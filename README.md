# Paper Trader demo

A read-only demo of the Paper Trader dashboard that runs entirely in your browser.

- It shows a recorded snapshot of a demo account. All prices are simulated and all trades are paper trades. No real money is involved.
- Nothing you do here is sent anywhere. Buttons that would change something are turned off.
- There are no accounts and no sign-in.

The application's own code is kept in a separate private repository. This site is generated from it.
